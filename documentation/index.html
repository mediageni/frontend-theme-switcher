Frontend Theme Switcher

Let each visitor preview approved installed themes without changing the site's active theme.

Documentation for version 1.0.2 · Updated 28 August 2026

Requirements

  • WordPress 6.4 or newer.
  • PHP 7.4 or newer.
  • At least two installed, working WordPress themes for a useful preview.
  • Administrator access to choose which themes are publicly available.

Installation

  1. Sign in to WordPress as an administrator.
  2. Open Plugins → Add New Plugin → Upload Plugin.
  3. Select frontend-theme-switcher.zip, install it, and activate it.
  4. Open Settings → Theme Switcher.

Activation does not change the site's current theme.

Configuration

Available themes

Select only themes that visitors may preview. Every selected theme must already be installed and free of WordPress theme errors. Test its menus, widgets, templates, and plugin layouts before enabling it publicly. Each preview uses that theme's own Customizer settings, including its logo, colors, and header-display choices, without changing the globally active theme. When an approved child theme exists, the plugin hides its parent theme from the public list while WordPress continues to load that parent internally.

Automatic placement

Select one conventional WordPress menu as the shared top navigation. Classic preview themes receive that menu in their header locations without changing their saved theme settings. Block themes continue to render their native Navigation block. When enabled, the switcher is appended after the first frontend navigation.

If a selected theme renders no usable WordPress navigation, a compact fixed top navigation displays the same menu links and switcher so the visitor can always move around the demo or switch back.

Data removal

Settings are preserved during deactivation. Enable Delete plugin settings when the plugin is uninstalled only when you want uninstalling the plugin to remove its settings permanently.

Visitor experience

The switcher uses an accessible native disclosure control. A tiny dependency-free script prevents third-party theme menu scripts from intercepting its controls. A visitor opens it, selects a theme, and returns to the same clean URL rendered with that theme.

The selection is stored in the functional sgfts_theme cookie for up to 30 days. Selecting the site-default theme removes the cookie. One visitor's selection never activates a theme globally and does not affect other visitors.

Manual placement

If the theme uses a custom header that does not render a standard WordPress navigation, disable automatic placement and add this shortcode where the switcher should appear:

[frontend_theme_switcher]

You can use a Shortcode block in the Site Editor, a page builder shortcode element, or a widget area that processes shortcodes.

Caching

Visitor-specific theme pages define the WordPress DONOTCACHEPAGE constant and send no-cache headers. Most WordPress page-cache plugins respect these signals.

Reverse proxy or CDN: if a cache ignores WordPress headers, configure it to bypass full-page caching whenever the sgfts_theme cookie is present. Never cache an alternative-theme response as the shared public page.

Privacy

The plugin stores only an installed theme's stylesheet identifier in a first-party functional cookie. It does not collect personal data, use analytics, load remote assets, or transmit information to MediaGeni or another external service.

WordPress adds suggested disclosure text under Settings → Privacy. Review it against the website's own legal requirements.

Deactivation and uninstall

Deactivation preserves all settings. Visitor cookies are ignored while the plugin is inactive. Uninstall removes settings only on sites where the administrator explicitly enabled the data-removal option.

Troubleshooting

The switcher is not in the header

The theme may use a hard-coded or builder-specific header instead of a standard WordPress navigation. Use the shortcode in that header's shortcode or HTML-capable element.

The wrong visitor sees a selected theme

This indicates shared HTML caching. Purge the page cache and configure the cache to bypass requests containing the sgfts_theme cookie.

A selected theme looks incomplete

Each theme owns its menus, widget areas, Site Editor templates, Customizer settings, and theme modifications. Configure that theme before exposing it, or remove it from the allowed list.

A removed theme was selected previously

The plugin rejects unavailable or unapproved themes, removes the stale preference, and falls back to the site's active theme.
